# 电机②真实滑块拖动：已复现约4°持续振荡

2026-10-24，Asia/Shanghai。使用 ego-browser 的真实鼠标按住、移动、松开网页电机②目标滑块；同时以 ST-Link 只读读取角度及控制状态。未修改固件、控制参数或校准。

## 已确认现象

真实拖动目标：11°→16°→21°→16°→11°→6°→11°。每段约5°、持续按住滑块移动，网页实际生成0.5°间隔的连续输入，UART ACK确认已到达MCU。松开后目标保持11°约2秒，再明确点击停止。

**已复现用户描述的持续抖动**：松开滑块后目标恒为11°，反馈仍在 **8.812°～13.040°**之间往复，峰峰值 **4.228°**，标准差 **1.147°**，主要频率估计 **13.15Hz**。这次数据不再支持之前短测的“未复现”结论；之前记录只描述当时的运行现象。

| 阶段 | 反馈角度标准差 | 角度总波动 |
|---|---:|---:|
| 关闭EN基线 | 0.044° | 0.205° |
| 松开滑块，11°固定目标 | 1.147° | 4.228° |
| 停止1秒后 | 0.045° | 0.192° |

停止后抖动明显衰减。这个对比支持抖动与当前使能闭环运行相关；尚未隔离校准、驱动电气、机械共振、反馈延迟和环路参数等因素。

## 主要排查线索：电压输出斜率与速度环

已读到电机② PID output_ramp=10V/s、velocity_limit≈1.047rad/s、P_angle.P=8。当前本地 SimpleFOC PID实现先计算P/I/D，再限制输出相对上次输出的变化率；因此这个参数约束的是电压指令的纠偏速度，不是超速故障阈值。

在13.15Hz保持振荡中，重建的未施加斜率限制的PI请求分量约0.378V，实际Uq分量约0.127V，约落后67°（约14ms）。这是对约20ms间隔、非原子RAM采样的近似频率投影，不是精确相位裕度辨识，重建PI也不是现场记录的pre-ramp变量。**它支持“输出变化率限制可能引入纠偏延迟”的假设，尚不能替代单参数A/B测试。**

电压指令在松开滑块后的约2秒中换号53次，积分仅约-0.026～0.014V，符合持续往复纠偏；本次没有发现之前无位置响应时那样的明显积分持续累积。

建议下一步只对电机②逐步放宽输出变化率，保持其他参数及保护不变，重复同样滑块轨迹，比较固定目标峰峰值和收敛时间。若没有改善，再单独检查速度滤波、PI、FOC校准与机械耦合。不要同时改变多个参数，否则无法判断改善来源。本次没有执行调参。

## 采集与限制

- SWD角度读取11414次，平均间隔2.63ms（约380Hz），覆盖11019个不同PWM sequence；控制量1427次。原始SWD不是原子快照，会跨PWM更新边界，存在重复时间戳和遗漏帧，不能视为完整的458Hz硬件帧记录。
- 频率估计基于固定目标窗口、PWM捕获时间戳；可作抖动频率近似，不用于精确系统辨识。

- 未暂停CPU，未复位或烧录。RAM成员布局沿用上级 `debug-build.json` 的ABI校验方法；采集前重新核对6V/P/I/方向与当前零点，结束后读取斜率、速度限制、角度增益见 `live-constants.log`。
- 没有实际母线电压、相电流或独立机械测量。此次调试读取也可能影响总线时序；在调参A/B中应包含关闭SWD的串口对照。

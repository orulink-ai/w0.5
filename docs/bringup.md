## 当前上板状态（2026-10-24）

下文按阶段保留验证过程。最新接法为 EN→PB5，与外部 3.3V 直连已移除，R78 保留 100Ω。用户明确要求保持原板直接高低电平控制；已说明这不能消除约 26mA 理想负载估算所对应的 GPIO 驱动风险。限时软件不能作为电气限流或长期额定运行认证。

此前 `g431_enable_uart` 完成真实网页开启高电平、手动关闭低电平、五秒自动关闭验证。随后已烧录 `g431_motor_gpio`，通过 ST-Link 校验并持续报告 READY：PB5 IDR/ODR bit5 为0，TIM1 中心对齐、PSC=0、ARR=319、CCR1/2/3=0，PA8/9/10 AF6，即25kHz下的零占空比。AS5600约460Hz、单圈约24°，角度曾由操作者手动改变。

网页已增加“低速转动 · 3秒”和“立即停止”。点动自动开启EN并在正常结束时关闭，允许操作者用新编号再次点动，不自动重发；四个角度定位按钮仍禁用。没有给新GPIO固件发送开始指令，电机接好/状态READY不能视为真实转动已验收。操作步骤见 `firmware/stm32/examples/encoder_read/MOTOR_GPIO.md`。

网页真实 STOP 已验收：收到 `#MOTOR_ACK,<id>,STOPPED` 和 DONE，PB5仍读低，开始按钮可供操作者点击；状态超时显示未知、禁用开始但保留停止尝试。390px无横向溢出。五套C++与40项Python测试通过，未给新固件发送JOG。

## 验证顺序

1. 锁定芯片与工具链，分别编译、烧录最小工程，验证串口日志。
2. 先为协议编解码和异常输入写主机测试，再实现协议；测试截断、损坏、边界值与版本不兼容。
3. 在主机测试运动状态机：上电、使能、停机、超时、故障、复位及陈旧命令。
4. 两板联调握手、心跳与遥测，断线和重启测试通过后再连接电机输出。
5. 在受控供电、限流和机械约束条件下验证单电机采样、方向与停机行为，再扩展多电机。
6. 最后接入 Wi-Fi 上层命令，验证网络断开与延迟不破坏本地控制和故障处理。

没有目标工具链或实机时，应明确记录“未编译”或“未进行实机验证”，不得以主机测试代替。

## 2026-10-24：当前 MP6536 单电机接线方案

用户提供 `DengFOCmini_mp6536(1).pdf`，单页原理图。该图是 MP6536 版本，不是前述 DRV8313 版本。后续提供的 DengFOC Mini 产品正反面图与该接口布局相符，但产品图不能证明手中实物的芯片标记和全部焊接阻值。

按产品图的**背面视角**（右边为电源正负口，下边为 A/B/C 三相口），控制排针丝印从左到右为：

```text
GND  FLT  EN   GND
IN1  IN2  IN3  VCC
```

这是背面方向；翻到元件面后左右会镜像，实际接线应逐个对照丝印。背面图电源口上方为负极、下方为正极，板上标称 5V～24V；底部 A/B/C 从左到右分别对应 OUT1/OUT2/OUT3。产品图中 EN 指示灯支路的电阻字码不可辨认，用户随后已确认实物 R78 为 100Ω，处理方案见下文。

| 驱动板接口 | 接线 |
| --- | --- |
| H1-1 VCC | 现有外部 3.3V 逻辑电源；这是外部供电输入，不能接 12V，也不是 DRV8313 的 LDO 输出 |
| H1-2 / H1-8 GND | 公共地：STM32 GND、AS5600 GND、外部 3.3V GND 相连 |
| H1-7 IN1 | STM32 PA8 / TIM1_CH1 |
| H1-5 IN2 | STM32 PA9 / TIM1_CH2 |
| H1-3 IN3 | STM32 PA10 / TIM1_CH3 |
| H1-4 EN | 接线阶段先接 H1 GND 禁用；未来拟分配 PB5，但必须先核对下述 R78 负载 |
| H1-6 NFLT | 拟分配 PB4 作带上拉的输入，低有效；本阶段可先不接，不作输出驱动 |
| CN2-3 OUT1、CN2-2 OUT2、CN2-1 OUT3 | 分别接电机三根相线，记录并保持相序；不接 MCU 或编码器 |
| U20-2 DCBUS | 独立电源口正极，后续接 12V 正极 |
| U20-1 PGND | 独立电源口负极，后续接 12V 负极；按实物正负丝印确认，不凭图纸左右插线 |

STM32 继续以 Type-C 供电，不将 STM32 3V3 输出和外部 3.3V 输出并联。AS5600 保持 OUT→PA0，TTL RXD→PA2，SWD 保持 PA13/PA14。PA8→PA0 回环线已移除。PA9/PA10 丝印可能标 UART1 TX/RX，但此处复用为 TIM1 PWM，与 PA2 的 USART2 日志不冲突。本机固定 STM32duino variant 已核对三个 TIM1 通道映射。

MP6536 的 PWM 输入高/低控制对应桥臂，EN 接 SHDNB，低电平关断；STBYB 通过 R76 10k 上拉到 VCC。NFLT 是 FAULTB 开漏故障输出，该图 LED 支路不能代替固件中的可靠上拉。芯片支持 3.3V 逻辑电平（数据手册输入高门限最大 1.8V）；电机电源 12V 在芯片 5～26V 工作范围内，这不等于 PCB 连续电流或电机负载已经验证。

**EN 负载问题（用户已确认 R78 为 100Ω）：** 原理图将 EN 同时经 R78 驱动 Q1（SS8050）的基极，R79=10k 为基极下拉。按理想 3.3V 驱动、约 0.7V 基极压降估算，基极支路约 26mA，超过 STM32G431 数据手册给出的 20mA 宽松电平输出驱动条件；这是负载估算，并非实测 GPIO 电流。因此不直接让 PB5 输出高。推荐断开 12V、USB、外部逻辑供电后，将**板上 R78 替换为 2.2kΩ**（基极支路约 1.2mA，原理图 R82=2k 的指示灯支路可继续使用）；不能改板时采用另行确认型号和接法的外部缓冲器。仅在 EN 线外随意串电阻可能同时拉低 SHDNB 电平，不能据此当作解决方案。用户最近确认实际已经将 EN 接至 PB5，R78 仍为 100Ω；现有固件 PB5 始终输出低，没有尝试拉高或使能。

目前只给出断电接线方案，尚未改动或烧录电机固件，仍在运行已验收的 AS5600 UART 读角程序。12V 暂不上电，接线完成和 EN 问题确认后再实现驱动初始化、默认禁用、故障/反馈超时关断及低电压单轴测试。电机功率线直接连接驱动端子。

参考：[MPS MP6536 数据手册](https://www.monolithicpower.com/en/documentview/productdocument/index/version/2/document_type/Datasheet/lang/en/sku/MP6536/document_id/3761/)、[STM32G431 数据手册](https://www.st.com/resource/en/datasheet/stm32g431cb.pdf)。

## GB2806 参数确认（2026-10-24）

用户提供电机外观及 GB2806 参数表：额定电压 12V、额定电流 0.81A、额定扭矩 0.06N·m、额定转速 950rpm、最大转速 2335rpm、堵转电流 1.22A、相电阻 5Ω、KV=121rpm/V、极对数 7；绕组匝数 60 与极对数是不同参数。相电感数值为 1.51，图中单位写作 Mh，未向供应商确认前不据此写入 SI 单位电感配置。以上是用户提供的标称值，尚未实测，额定/堵转电流不能替代运行中的电流检测或电源限流。

该三相 BLDC 可沿用 SimpleFOC：电机对象的必需极对数使用 `BLDCMotor(7)`，驱动对象对应 PA8/PA9/PA10 三路 PWM，AS5600 保持 PA0 反馈；使用角度模式并先做低速、低输出电压测试。当前未确认相电流采样，计划先采用电压力矩模式下的位置闭环，不声称已有电流/力矩闭环。约 460Hz 的 PWM 反馈不用于承诺参数表最大转速下的闭环性能。

电机极对数这一待确认项已解除；后续驱动板产品图也已确认背面 H1 丝印布局，用户进一步确认 R78 实物为 100Ω。当前需落实上述替换电阻或外部缓冲的使能方案。传感器回调的待烧录源码已改为每次直接解码硬件捕获，避免未来阻塞式 FOC 校准读取主循环缓存；负值只表示反馈无效，不代表已实现电机故障关断。尚未改写正在运行的目标暂存固件，也没有让 PB5 输出高或使能驱动。

参考：[SimpleFOC BLDCMotor](https://docs.simplefoc.com/bldcmotor)、[SimpleFOC 3PWM 驱动接口](https://docs.simplefoc.com/bldcdriver3pwm)。实际代码接口以本机固定的 SimpleFOC 2.4.0 为准。

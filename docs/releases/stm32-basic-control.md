# STM32 单轴基础控制交付记录

日期：2026-10-24。状态：已构建、烧录并完成基础实机验证；本记录随位置／速度闭环控制版本保存，提交与远程分支以 Git 记录为准。

## 范围与行为

本版提供 AS5600 PWM 反馈下的位置伺服和速度闭环。位置模式按设定速度推进目标，到位后持续保持；速度模式按有符号 rpm 运行。没有固定 5 秒截止。网页每 300ms 维护本次运动的 1500ms 运行租约，关闭／刷新控制页或中断通信后停机，不自动重启。

网页默认移动速度已提高到 **3rpm（18°/s）**，可设范围 0.1～5rpm。它是轨迹／控制设定值，实际瞬时转速存在波动。参数修改需先停止，再手动启动。手拨阻力、柔顺回中、电流环和自动寻找机械限位不在本版范围内。

| 协议 | v3，运行心跳绑定当前 run_id |
| 固件占用 | Flash 67564 字节，RAM 4672 字节 |

PB4 配置为 nFAULT 输入，但实物故障线是否连接尚未确认。没有相电流或温度采样，本版不能据输出电压限制推断精确电流／力矩。

## 使用方法

1. 打开或刷新 <http://127.0.0.1:8840/>。确认串口连接、编码器有效。
2. 复位或重新上电后，先空载校准；需要时在停止状态设置用户零点。
3. 位置模式填写目标与移动速度，点击“启动并保持”；速度模式填写有符号 rpm 后启动。保持控制页面连接。
4. 点击停止释放输出，再手动转轴或修改参数。页面刷新后需要重新显式启动。

组件、坐标与协议说明见 [闭环架构](../closed-loop-architecture.md)，接线及启动命令见 `tools/encoder_dashboard/README.md`。

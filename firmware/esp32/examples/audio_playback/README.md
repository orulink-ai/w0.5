# 喇叭固件调试接入约定

[English](README.en.md)

状态：待接入实际固件，没有音频驱动或可烧录入口。此目录用于后续喇叭验证，不能作为已经实现播放的证明。

拿到固件后将源码、板型配置、依赖锁定和独立构建入口整理在本目录；音频资产需记录来源和许可证。先确认主芯片、功放 / DAC 型号、I2S 或其他接口、引脚、供电、采样率和串口，再提供构建与烧录命令，避免误用摄像头引脚或镜像。

摄像头源码和入口保留在 `../imx708_usb/` 与 `tools/camera.py`，不得被喇叭工程覆盖。喇叭使用独立 build 目录；不自动复用 COM15，不自动烧录，不在启动摄像头时播放声音。若最终运行在同一块 P4，需明确是临时替换应用还是整合音视频任务，并核对 I2S / CSI / UART 引脚、内存和调度资源；共用串口前先关闭摄像头预览。

后续验收记录固件提交、硬件型号、音量上限、播放 / 停止、重复播放及摄像头并行运行结果。未经执行的项目标为待测，不填写推测结果。

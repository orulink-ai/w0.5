# STM32 自动化单元测试

后续覆盖双轴状态、使能与停机、通信超时、目标过期、故障及复位。通过替身隔离采样、输出与时钟。

已提供 AS5600 PWM 解码与边沿捕获的主机测试：在仓库根目录运行 `python3 tools/stm32.py test`。覆盖角度范围、四档 PWM 频率、同帧配对、缺失边沿、信号过期及计时回绕，使用 CMake/CTest + 主机 C++ 编译器。上板验证程序放在 `../examples/`，不能以主机测试替代。

新增 `angle_target/` 主机测试：有界行缓冲、0/90/180/270 四目标、请求编号、CRLF/分段输入、重复与冲突、数值溢出、非法命令及超长行恢复。目标接收模块仅暂存数据，不包含驱动或 GPIO 访问，不能作为实际运动状态机验收。

新增 `motor_jog/` 主机测试：上电不转、连续有效反馈 500ms 后才能显式启动、三秒截止、重复命令不延期、旧手动 EN 环境每次启动仅一次运行、反馈失效、STOP、计时回绕及有界串口命令。

`enable_control/` 验证默认关闭、显式开启、5秒关闭、重复请求不延期、反馈失效、故障、OFF 幂等与运动内部使能的独立编号。`motor_gpio/` 验证 GPIO 门控运动策略、正常结束后新编号可再次点动、旧编号不可重放、STOP 高水位与反馈/使能失效终止。`tools/stm32.py test` 运行全部五套 CMake/CTest；它们不验证实际电机转动、GPIO 电流或硬件故障路径。

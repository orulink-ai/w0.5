# PB5 使能下的手动低速点动

用于 GB2806 首次三相接线测试：网页由操作者显式开始、提前停止，正常结束后允许新命令再次点动。不是位置闭环，四个角度目标按钮仍禁用。

## 接线

| 接口 | STM32 / 电源 |
| --- | --- |
| DengFOCmini IN1 / IN2 / IN3 | PA8 / PA9 / PA10，TIM1 三路同步 PWM |
| DengFOCmini EN | PB5，高有效；不再直连外部 3.3V |
| DengFOCmini VCC | 现有外部 3.3V 逻辑电源 |
| 独立电源口 + / − | 12V 正极 / 负极 |
| A / B / C | 电机三相线，固定记录相序 |
| AS5600 OUT | PA0 / TIM2，约 460Hz PWM |
| TTL RXD / TXD | PA2 / PA3，USART2 115200 |
| GND | MCU、编码器、驱动逻辑和外部电源公共地 |

GB2806 标称 12V、7 极对、相电阻 5Ω、额定 0.81A；程序只传入已确认的极对数 `BLDCMotor(7)`，先用电压力矩模式下的速度开环。AS5600 独立用于读角及反馈有效性检查，没有做电角度校准或位置闭环。

用户明确选择保留板载 R78=100Ω 并直接由 PB5 驱动，已告知其 EN 指示灯三极管支路负载可能超出 MCU 推荐驱动条件。没有测量 GPIO 电流，也未证明长期额定可靠；5秒/3秒限时及数字电平读回不能替代电气限流。驱动 nFAULT、相电流采样尚未接入，程序不声称有电流闭环或硬件急停。

## 操作

1. 初次烧录及检查时保持 12V 关闭，STM32 和逻辑电源正常连接。
2. 使用 `g431_motor_gpio` 固件；启动不旋转，PB5 默认低，TIM1 各路占空比为零。程序报告电机 READY 和使能低电平，AS5600 信号有效后才允许开始。
3. 保持轴空载、手离开转动部件，并保留手动切断 12V 的方式，再上电。
4. 刷新 `http://127.0.0.1:8840/`，点 **低速转动 · 3 秒**。该命令会自动开启 EN，无需先点使能。速度目标 0.5rad/s（约 4.8rpm），电机调制电压幅值 1V，PWM 瞬时电压仍为 12V。
5. 观察转轴和实际编码器角度。点 **立即停止** 可提前结束；约三秒后程序也会关闭 EN 并归零三相 PWM。正常停止、EN 读回低后可再次显式点击，不自动重复。
6. 异常、抖动、过热或接线不确定时关闭 12V。FAULT 不自动恢复，需要断电检查后复位。原四角按钮不代表实际位置控制。

“收到 STARTED”只表示 MCU 接受了开始请求；电机是否真实转动，需结合操作者观察和连续编码器角度变化判断。开环转动的方向、角度与到位精度没有保证，不能把三秒作为精确转过某个角度。

## 代码与协议

```sh
python3 tools/stm32.py test
python3 tools/stm32.py build --env g431_motor_gpio
```

- `motor_gpio.cpp`：独立上板入口。`BLDCDriver3PWM` 不接 enable 参数，避免 SimpleFOC 的初始化自动拉高 EN；PB5 全部由 `enable_output` 管理。
- `enable_output`：显式使能高低电平、5秒上限、引脚读回、看门狗与故障。运动内部使能不改变独立 ENABLE 通道的编号。
- `motor_gpio::Controller`：显式新编号点动、三秒截止、正常停止后重新点动、旧编号不可重放、传感器失效/外部关闭使能时结束。
- MOTOR 串口：`MOTOR,<id>,JOG|STOP`，ACK `#MOTOR_ACK,<id>,STARTED|STOPPED`，NACK `#MOTOR_NACK,<id>,<reason>`，状态 `#MOTOR_STATUS,1,READY|RUNNING|DONE|FAULT,<high_water_id>`。
- JOG 必须是更大的新编号；STOP 即使是旧编号也执行，不能降低编号高水位。后端重启根据 MCU 状态续号。所有自动重发、自动继续运动均禁用。
- 3PWM 使用 STM32 强后端，环境固定 `lib_archive = no`，避免库归档先选中 generic weak `analogWrite` 实现。HSI16 下 TIM1 中心对齐、PSC=0、ARR=319 对应 25kHz。
- 初始化中 EN 始终低；先暂时延长已运行的看门狗，以跨过 SimpleFOC 初始化的一秒等待，之后恢复约100ms。真实看门狗复位保持故障，不自动运行。

## 验证边界

主机策略和伪串口测试不能证明电机实际转动、GPIO 电流、功率输出波形或驱动保护有效。上板会先验证启动默认关闭、状态反馈和停止请求，实际 JOG 留给操作者点击；最终实测记录应据真实数据补充。

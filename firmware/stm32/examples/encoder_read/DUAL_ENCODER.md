# 双 AS5600 PWM 采集

现已增加完整的 [双电机闭环环境 `g431_dual_motor`](DUAL_MOTOR.md)，每颗编码器参与对应电机控制。下面保留单电机加第二路读数和独立诊断环境的说明。

## 正常使用：第一路电机闭环 + 第二路编码器显示

当前使用 `g431_closed_loop`：原电机的 PA0 反馈、PA8/PA9/PA10 PWM、PB5 EN、控制参数和 UART 命令保留。第二颗 AS5600 的 OUT 接 PB7，复用下表的 3.3V 和共地接法。无需第二路电机驱动即可读取两颗编码器；PB12 始终输出低电平。

独立的 `SecondaryEncoderMonitor` 初始化 TIM4 并读取 PB7，与 PA0/TIM2、PWM/TIM1 分离，不持有电机、校准或运行租约的引用。每 100ms 尝试输出一条辅助遥测，使用固定栈缓冲及 Arduino Print 浮点格式化，整行有串口空间才发送，否则丢弃该帧。避免依赖 nano printf 未启用的 `%f` 支持，发送长度按实际生成的字节数计算。

```text
#ENCODER_AUX,1,2,OK,224.02,0.000,455.9,1349,2193
```

辅助记录只更新第二张卡片。其信号无效不会关闭第一路控制，不能冒充 PA0 反馈；原第一路遥测及 `#FOC_STATUS,4,...` 协议保持原样。使用 `python3 tools/stm32.py upload --env g431_closed_loop` 烧录，然后刷新网页、按原流程校准和手动启动。

2026-10-24 恢复实测：闭环固件烧录校验通过，连续 30 次网页 API 采样均为闭环能力有效、故障 NONE、两路编码器有效。浏览器点击原“立即停止 / 关闭 EN”，芯片 ACK 接受 STOP、报告 USER_STOP 且 EN 关闭；校准按钮可用，未自动校准或启动电机。80 项 Python 测试、六套原生 C++ 测试及控制/拖动/租约/双读数网页组件测试通过；尚未对附加采集后的电机运动做实测。

## 可选：独立只读诊断固件

独立环境 `g431_dual_encoder` 仅检查两颗编码器，不提供双电机控制。
启动时 PB5、PB12 两路 EN 和六个相控制脚均输出低电平；串口收到的运动命令会被丢弃。
使用本诊断时关闭驱动 12V，保留 STM32、串口和编码器供电。

| 接线 | 编码器① | 编码器② |
| --- | --- | --- |
| OUT / PWM | PA0 | PB7 |
| 电源 | 已验证的外部 3.3V | 同一路外部 3.3V |
| GND | 与 STM32、外部电源共地 | 与 STM32、外部电源共地 |

USART2 接线保持不变：STM32 PA2/TX → TTL RXD，PA3/RX → TTL TXD，GND 共地，TTL 供电脚不接。

```sh
python3 tools/stm32.py build --env g431_dual_encoder
python3 tools/stm32.py upload --env g431_dual_encoder
python3 tools/stm32.py dashboard --port /dev/cu.wchusbserial1110
```

串口路径按当前设备选择。打开 http://127.0.0.1:8840/，两张卡片分别显示角度、频率、脉宽、周期、有效帧数和数据年龄；无效或超时只清空对应一路。分别手动转动两根轴，检查只有对应卡片的角度变化。

固件以 10Hz 分别发送如下九字段记录，通道编号为 1 或 2：

```text
#ENCODER,1,1,OK,296.35,0.004,459.5,1750,2176
#ENCODER,1,2,OK,45.57,-0.006,457.9,324,2184
#ENCODER,1,2,NO_PWM_OR_INVALID,nan,nan,nan,0,0
```

网页收到诊断记录后撤销旧电机控制能力，保留原单路角度仪表、位置/速度控制和拖动滑块，显示诊断提示并禁用运动按钮。恢复闭环固件后按原流程校准和启动；旧版未标记的角度记录仅归入①，不会复制到②。

PA0 使用 TIM2、8MHz；PB7_ALT1 使用 TIM4_CH2、4MHz，CH1 间接捕获同一输入的下降沿。TIM4 为 16 位，4MHz 可覆盖 115Hz 编码器的完整周期。构建必须包含项目 `clock.cpp`，使用 HSI16 时钟，保证计数分频可整除；默认板级时钟不适用于当前计数频率。

2026-10-24 实板：ST-Link 烧录校验通过，串口两路均有效。连续约 3 秒的 30 次网页 API 采样中，两路均 30/30 有效：①约 296.34～296.39°、459.2～459.7Hz；②约 45.51～45.61°、457.7～458.0Hz。此结果验证同时读取，仍需分别手动转轴确认实际通道对应关系。未启动电机。

已通过 PWM 捕获原生测试、Python 后端及网页组件测试；`g431_closed_loop` 环境编译通过。诊断入口由编译宏隔离；第二路捕获模块由诊断环境和闭环环境共同使用。
